Feed Switcher FS-006 / v0.6.0 — Privacy & Compliance 验收
===========================================================

推荐：使用 Dev Kit 中的 Backend_Lite + Chrome_Loadable。

0. 升级注意
---------
如果你从 v0.5.1 直接升级，Chrome 本机 storage 会保留旧的同步账号连接；但全新 FS-006 Backend_Lite 文件夹没有旧账号数据库。
如果 Popup 显示“已连接”但新 Backend 不认识旧账号，请先点击“断开本设备”，再用 FS-006 新建一个测试同步账号。

1. 启动 Backend Lite
------------------
Windows：双击 Backend_Lite/start-backend.bat
保持黑色窗口开启，确认显示：
Feed Switcher Backend Lite / FS-006
Listening: http://127.0.0.1:8787

2. 加载 Chrome 扩展
-----------------
chrome://extensions -> 开发者模式 -> 加载已解压的扩展程序
选择 Chrome_Loadable 文件夹。
确认版本为 0.6.0。
已打开的 YouTube 页面升级后刷新一次。

3. 隐私同意 Gate
---------------
打开 Popup。
应看到：
- “云同步数据说明”复选框
- “隐私与数据”链接
- “使用条款”链接

保持复选框不勾选：
- 点击“创建同步账号” -> 必须被明确阻止并提示先同意数据说明。
- 如果已有账号，上传本机/下载云端也必须被阻止。

勾选复选框：
- 应显示已记录同意；
- 创建/连接/上传/下载恢复正常。

再次取消勾选：
- 上传/下载/创建/连接应再次被阻止；
- “断开本设备”和“删除云端账号”仍必须可用。

4. 隐私与数据中心
---------------
点击 Popup 的“隐私中心/隐私与数据”。
新标签页应显示：
- 当前本机频道/收藏/最近使用摘要
- 当前云同步连接摘要
- 明确“不收集”的数据列表
- 数据保留期限
- 云同步同意状态
- YouTube Terms / Google Privacy 链接

5. 导出本机数据摘要
-----------------
点击“导出本机数据摘要”。
应下载 feed-switcher-privacy-export-YYYY-MM-DD.json。
打开文件检查：
- 包含 settings / profiles / privacy consent / cloud connection metadata；
- 不得包含完整 fs1 同步密钥；
- excludedSecrets 应包含 syncKey。

6. 删除云端账号
--------------
先保证已经建立一个 FS-006 测试同步账号并上传过数据。
在隐私中心点击“删除云端账号”：
- 应有强确认；
- 成功后云端账号被删除；
- 本地收藏与最近使用仍存在；
- 原 fs1 密钥再次连接应失败/无效。

注意：运维事件中的哈希化删除事件可最多保留 30 天；账号和同步快照本身应立即删除。

7. 清除本机数据
--------------
建议在删除云端账号后测试。
点击“清除本机 Feed Switcher 数据”：
- 应有强确认；
- 收藏/最近使用/同步连接/同意记录被清除；
- Feed Switcher 恢复默认 Level A 设置；
- 不应卸载扩展。

8. 回归测试
----------
重新设置几个频道，确认以下旧功能仍正常：
- FS 右下角入口
- Topic / 语言 / 地区 / 时间 / 优先级
- 进入频道
- 收藏 / 最近使用 / 快速切换
- 本地 JSON 导入导出
- Popup 内实时开启/关闭
- Gate 仍为 LEVEL_A，高级 Flag 全部 OFF

9. FS-006 不要求验证的外部项
-------------------------
以下需要在 FS-007 Chrome Beta 前填写/部署，但不影响本机 FS-006 验收：
- 正式运营主体/名称
- 公开支持邮箱
- HTTPS 官网与 Privacy/Terms URL
- 正式 HTTPS API 域名

这些值目前没有被虚构，模板位于 Source/compliance/。
