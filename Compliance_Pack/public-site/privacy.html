1. Who operates Feed Switcher

Feed Switcher is operated by {{OPERATOR_NAME}}. Contact: {{SUPPORT_EMAIL}}.

2. What Feed Switcher does

Feed Switcher helps users configure topic discovery through native YouTube search, save interest profiles and optionally sync those profiles with a local development or self-hosted backend. Region, language and time settings are search hints and do not guarantee result eligibility. No hosted service or AI creator analysis is included.

3. Local data

The extension stores settings, favorite channel configurations, recent Feed Switcher channel configurations, privacy-consent state, cached feature-control configuration and—if cloud sync is connected—a pseudonymous account identifier and sync key in Chrome local extension storage.

4. Optional cloud sync

Cloud sync is opt-in. When enabled, Feed Switcher transmits the user’s discovery configuration, favorites and recent Feed Switcher channel configurations to its backend. It does not sync Chrome browsing history, YouTube viewing history, YouTube search history, cookies, email addresses or passwords.

5. Authentication and operational data

Cloud sync uses a pseudonymous sync key. The raw secret is kept on the user’s device and is transmitted to authenticate explicit sync requests; the server stores only a SHA-256 hash of the secret. Minimal operational events may contain an allowlisted event type, a hashed account identifier, status, client version and timestamp. Operational events have a 30-day retention target. With the configured hourly cleanup running normally, deletion may occur up to one hour after expiry; a stopped local server resumes cleanup at its next startup. Operators must separately verify failed jobs and backup retention.

6. How data is used

Data is used only to provide Feed Switcher functionality, synchronize user-selected configurations, secure/authenticate the sync account, and operate/troubleshoot the service. Feed Switcher does not sell user data and does not use it for personalized, retargeted or interest-based advertising.

7. Sharing and human access

User data is not shared except as necessary to operate the service, comply with law, address security/abuse, or as part of a merger/acquisition subject to applicable requirements. Human access to synced user data is prohibited except when the user explicitly requests support for specific data, when necessary for security, when required by law, or after aggregation/anonymization for internal operations.

8. Chrome Web Store Limited Use

Feed Switcher’s use of information received from Chrome extension permissions and user interactions adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide or improve Feed Switcher's single user-facing purpose, is not sold, is not used for personalized/retargeted/interest-based advertising, and is not made available for human reading except for user-requested support on specific data, security/abuse investigation, legal requirements, or aggregated/anonymized internal operations.

9. Retention and deletion

Local data remains until the user clears extension data or uninstalls the extension. Cloud sync snapshots remain until the user deletes the cloud account. Cloud-account deletion permanently deletes the account and its sync snapshot. Operational event metadata follows the cleanup limits described in section 5.

10. Security

Production network transmission must use HTTPS. The local HTTP Backend Lite included with development builds is solely for same-device developer acceptance testing and is not the production service.

11. YouTube and Google

The FS-006 Level A build does not use the YouTube Data API. Before YouTube API Services are enabled, this policy will be updated as required. YouTube Terms: https://www.youtube.com/t/terms. Google Privacy Policy: https://policies.google.com/privacy.

12. User controls

Users can export a privacy-safe local data summary, delete their cloud sync account and clear local Feed Switcher data from the extension’s Privacy & Data Center.

13. Changes

If data types or purposes materially change, Feed Switcher will update this policy and request renewed consent where required.
