Delete Feed Switcher Data

Open Feed Switcher → Privacy Center.

Delete cloud data

Select Delete cloud account. This permanently deletes the pseudonymous cloud account and sync snapshot and removes the local sync connection. Local favorites remain unless you separately clear local data.

Delete local data

Select Clear local Feed Switcher data. This removes local settings, favorites, recents, cached Gate state, sync key and privacy-consent record, then restores default settings.

Clearing local data does not automatically delete an existing cloud account. For complete deletion, delete the cloud account first and then clear local data.
