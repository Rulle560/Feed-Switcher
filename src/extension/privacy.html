FS-006 · Privacy & Compliance

隐私与数据中心

Feed Switcher 采用最小数据原则。Level A 不读取或上传你的 YouTube 观看历史、搜索历史、浏览器历史、Cookie、邮箱或密码。

明确不收集

YouTube 观看历史YouTube 搜索历史浏览器历史Cookie邮箱密码支付信息通讯录

当前 Level A 仅在 YouTube 页面注入 Feed Switcher UI，并构造用户主动选择的 YouTube 搜索。页面中的视频内容不会被上传到 Backend Lite。

保留期限

  • 本机数据：保留到你清除扩展数据或卸载扩展。
  • 当前同步快照：保留到你删除同步账号。自托管服务如有运营备份，其保留与清理需要部署者另行说明和验证。
  • 运维事件日志：仅记录事件类型、哈希账号标识、状态、客户端版本和时间，目标保留 30 天。正常运行时每小时清理，物理删除可能增加最多一小时的调度延迟；本机服务关闭期间无法清理，下次启动先执行清理。云服务须启用对应定时任务，本版本不提供公共同步服务。
  • 同步密钥：原始 secret 仅保存在用户设备；服务器只保存 SHA-256 哈希。

传输与访问

  • 当前本机 Backend Lite 仅用于开发验收；正式生产后端必须使用 HTTPS。
  • 不出售用户数据，不用于个性化/重定向广告。
  • 除用户明确请求的支持、安全调查、法律要求等有限情形外，不允许人工读取用户同步数据。
  • 服务器 Feature Flag 只能关闭高级能力，不能绕过本地 Gate 开启未获批准功能。

你的控制权

“断开本设备”只移除本机保存的同步密钥，不删除本地收藏或同步账号；“删除云端账号”会删除同步账号及其当前同步快照，不清除本地收藏，也不承诺删除自托管服务的所有运营备份。

Chrome Web Store Limited Use

Feed Switcher 对从 Chrome 扩展权限与用户交互中获得的数据，仅用于提供或改进本产品明确的单一用途。用户数据不会出售，也不会用于个性化、重定向或基于兴趣的广告。人工访问仅限于用户明确请求的特定支持、安全/滥用调查、法律要求，或经聚合匿名化后的内部运营。

平台条款与未来 API 功能

当前 FS-006 Level A 不使用 YouTube Data API。未来 Gate 2/3 功能启用 YouTube API Services 前，会按适用要求更新隐私政策、数据保留规则、用户同意和 YouTube 条款披露。
