Feed Switcher 使用条款

本地优先的开源 Beta · 2026-10-07。源码按 MIT 许可提供，完整许可见发行包随附的 LICENSE。

1. 产品用途

Feed Switcher 帮助用户主动选择 YouTube 搜索主题、语言、地区、时间范围和优先级，并保存、收藏、切换自己的发现配置。界面中的“频道”指发现配置，不是 YouTube 发布者频道。本版本生成原生搜索 URL，不控制推荐算法或保证搜索排名，也没有已实现的 AI 创作者分析或视频评分。

2. 可选同步账号

本地功能不需要服务器。可选同步需要用户主动同意，并单独启动同一设备上的 Backend Lite；自托管适配器需部署者配置和验证。本版本不提供托管同步服务，也未开通收费服务。同步账号不要求邮箱或密码；用户必须自行妥善保管同步密钥，任何持有有效密钥的人都可能访问对应同步数据。Feed Switcher 不要求用户提供 YouTube 密码、Google 密码或邮箱密码。

3. 平台关系

Feed Switcher 是独立第三方项目，不隶属于 YouTube 或 Google，也未获得其官方认可。当前功能不使用 YouTube Data API。后续如加入平台 API 功能，需要另行检查适用的平台条款、许可和数据处理要求；本版本不声称已通过该类审核。

4. 禁止用途

不得利用 Feed Switcher 绕过平台访问控制、抓取被禁止的数据、侵犯版权、干扰 YouTube 服务、传播恶意软件，或从事违反适用法律与平台条款的活动。

5. Beta 与变更

Beta 功能可能变更、暂停或移除。不同 Chrome 版本、YouTube 实时页面布局和旧版升级路径尚未全部验证，已执行的检查与限制见发行包的验证记录。后续如改变平台 API 或数据处理范围，需要同步更新隐私说明、用户披露及相关审核记录。

6. 数据与删除

数据处理与删除方式以“隐私与数据中心”为准。删除同步账号会删除该账号及其当前同步快照；本机扩展数据需要独立清除。自托管服务的运营备份与日志有各自的保留和清理要求，本项目不承诺删除所有运营备份。
