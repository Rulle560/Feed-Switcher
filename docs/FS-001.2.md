# FS-001.2 — Dual-channel live toggle hotfix

## Problem
FS-001.1 still depended on `chrome.storage.onChanged` for live UI updates. Real-device acceptance showed state persisted correctly but the current YouTube page sometimes did not update until refresh.

## Fix
- Popup now awaits `chrome.storage.local.set`.
- Popup actively sends `FS_APPLY_SETTINGS` to the active tab.
- Content script applies settings synchronously via `chrome.runtime.onMessage`.
- `chrome.storage.onChanged` remains as a fallback channel.
- Popup displays whether the current page acknowledged the message.
- If the extension was just reloaded in Developer Mode and the existing YouTube tab has no current content script, the popup explicitly reports that one refresh is required to inject the new build. This is a development-update condition, not normal toggle behavior.
- No new manifest permissions were added.
