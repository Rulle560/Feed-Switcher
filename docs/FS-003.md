# FS-003 — Query Engine

## Goal
Turn saved discovery intent into a usable YouTube-native search flow without YouTube Data API dependency.

## Level A strategy
- No YouTube Data API.
- No backend.
- No scraping of result data.
- No derived metrics.
- No AI classification.
- The extension only builds a YouTube search request from explicit user choices and navigates the user to YouTube's own results page.

## Query mapping
- Preset Topic -> static localized topic seed.
- Custom Topic -> exact user text, never auto-translated in Level A.
- Language -> selects localized preset topic seed; not a hard language filter.
- Region -> `gl=<country>` localization hint when a non-global region is chosen.
- Time -> YouTube search `after:YYYY-MM-DD` operator.
- Relevance -> YouTube default ranking.
- Popular -> YouTube native Popularity `sp=CAMSAhAB` path.
- Latest -> fresh time-window discovery only. YouTube removed strict upload-date sorting in 2026, so FS-003 does not claim chronological ordering.

## Safety / honesty rules
1. Do not label Popularity as pure view-count sorting.
2. Do not claim strict language filtering at Level A.
3. Do not claim physical geolocation spoofing for `gl`.
4. Do not claim strict chronological sort for Latest.
5. Gate 2/3 features remain OFF.

## Acceptance
1. Topic selection generates a visible query preview.
2. Clicking “进入频道” saves settings and navigates to YouTube results.
3. 24H/7D/30D produce an `after:` date constraint.
4. Global does not add `gl`; a specific region does.
5. Popular adds YouTube Popularity sort token.
6. Latest + ANY automatically uses a 30-day fresh candidate window and displays the limitation.
7. Restore normal YouTube disables channel mode and navigates to YouTube home.
8. No permission increase and no external API/network dependency beyond normal YouTube navigation.
