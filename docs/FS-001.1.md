# FS-001.1 — 实时开关热修复

## 问题
FS-001 中 Popup 修改 `enabled` 后，content script 会收到 storage change，但关闭状态仍会重新挂载 UI；MutationObserver 也会在节点移除后继续尝试挂载，因此需要刷新页面才能真正反映状态。

## 修复
- `enabled=false` 时 content script 明确执行 `unmount()` 并停止渲染。
- `enabled=true` 时直接使用 storage change 的新值重新渲染。
- MutationObserver 仅作为 YouTube SPA DOM 变化后的恢复机制；恢复前重新读取设置。
- 增加 `mountInFlight`，避免 MutationObserver 高频触发导致并发重复挂载。

## 人工验收
1. 保持 YouTube 页面打开。
2. Popup 关闭“在 YouTube 启用”：FS 按钮应立即消失，不刷新。
3. Popup 重新开启：FS 按钮应立即出现，不刷新。
4. 在 YouTube 内部导航若 DOM 发生替换，只要插件仍启用，FS 应保持/自动恢复。
5. 访问非 YouTube 网站，不应注入 UI。
