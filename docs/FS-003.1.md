# FS-003.1 — Query semantics correction

## Changes
- Renamed “最新” to “近期” because Level A narrows a time window but cannot guarantee reverse-chronological order.
- Clarified “热门” is YouTube Popularity, not pure view-count ordering.
- Split generic Chinese into Simplified Chinese (`zh-Hans`) and Traditional Chinese (`zh-Hant`).
- Added Taiwan (`TW`), Hong Kong (`HK`), and Singapore (`SG`) region hints.
- Migrates legacy `zh` setting to `zh-Hans`.
- Query Preview now shows the applied `gl` region hint directly.
- UI explicitly states that Level A language selection is a relevance preference, not a hard language filter.
- Added cross-combination warnings for Chinese language/region pairs that naturally produce mixed-script results.

## Policy/architecture note
Strict language filtering remains outside Level A. YouTube's own `relevanceLanguage` behavior is relevance-biased and may still return other languages. Hard filtering will require later metadata/classification work under the project's Gate strategy.
