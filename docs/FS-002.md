# FS-002 — Topic UI

## Goal
Deliver the first user-facing topic control surface while remaining entirely inside Gate Level A.

## Included
- 11 preset topics + Custom Topic
- Language selector
- Region selector
- Time range selector
- Sort selector using only ordinary Level A concepts
- Persistent local settings (schema v2; v1 auto-migrates)
- Channel mode / normal YouTube mode state
- Restore ordinary YouTube action
- Popup shows current channel summary

## Explicitly excluded
- No YouTube Data API calls
- No derived metrics
- No AI topic classification
- No historical tracking
- No ranking / trend engine
- No external backend

## Acceptance
1. Existing 0.1.2 enabled state survives upgrade.
2. Clicking FS opens Topic UI without breaking YouTube navigation.
3. Topic/language/region/time/sort controls update summary.
4. Custom Topic requires non-empty input before channel mode is saved.
5. Saved settings persist after page refresh.
6. Restore ordinary YouTube sets channel mode inactive without disabling extension.
7. Popup reports the current saved channel.
