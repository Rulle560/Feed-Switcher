# FS-001 — MV3 工程骨架

## 实现内容
- Manifest V3。
- TypeScript 源码；Vite 作为 popup 本地 UI 开发环境。
- 生产扩展脚本采用确定性 `tsc --outFile`，避免 MV3 manifest 依赖 hash 文件名。
- 仅声明 `storage` 权限与 `https://www.youtube.com/*` host permission。
- 静态 content script 在 YouTube 页面注入最小 FS 入口。
- Service worker 在安装时初始化/迁移设置。
- Feature Flag 默认全部关闭。
- Popup 可开关 YouTube 注入状态并显示当前 Gate/Flags。

## Feature Flags
- API_ENHANCED_SEARCH=false
- DERIVED_METRICS=false
- AI_TOPIC_TAGGING=false
- HISTORICAL_TRACKING=false
- CREATOR_RANKINGS=false
- ALERTS=false

## 人工验收
1. Chrome 打开 `chrome://extensions`，开启开发者模式。
2. 选择“加载已解压的扩展程序”，加载 `dist/`。
3. 打开 `https://www.youtube.com/`。
4. 页面右下应出现 `FS` 浮动按钮；点击显示 FS-001 状态面板。
5. 点击浏览器工具栏 Feed Switcher 图标，Popup 应显示 `LEVEL_A`，六个高级 Flag 全部 OFF。
6. 关闭“在 YouTube 启用”，页面 FS 入口应变为弱化状态；重新开启恢复。
7. 访问非 YouTube 网站，不应注入任何 UI。

## 政策检查
- Single Purpose：YouTube 内容发现与 Creator Research。
- 无 `<all_urls>`、history、cookies、webRequest、tabs、scripting 权限。
- 无远程脚本执行；生产 JS 不包含远程 URL。
- Gate 2/3 高级能力默认关闭。
